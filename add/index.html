Address

Open in the app

How to join

  • In the game: Multiplayer, then Add Server, and paste the address as the server address.
  • In the MsgCraft app: “Open in the app” opens Add server with the name and address filled in. Nothing is saved until you tap “Add server”.

MsgCraft is coming to the App Store and Google Play soon. Until you have the app, “Open in the app” cannot open anything (your browser may show an error).

This link is incomplete

The server address is missing or not valid. Ask the person who sent it to share the server again.

The name and address come from whoever made the link; MsgCraft has not checked them. This page reads them from the part of the link after # in your browser only. That part is never sent to the web server, and this page stores and sends nothing.

공유받은 서버

주소

앱에서 열기

들어가는 방법

  • 게임에서: 멀티플레이 → 서버 추가를 누르고 서버 주소 칸에 붙여 넣으세요.
  • MsgCraft 앱에서: ‘앱에서 열기’를 누르면 이름과 주소가 채워진 서버 추가 화면이 열립니다. ‘서버 추가’를 눌러야 저장됩니다.

MsgCraft는 곧 App Store와 Google Play에 나옵니다. 앱이 없으면 ‘앱에서 열기’가 동작하지 않습니다(브라우저에 오류가 나올 수 있음).

링크가 완전하지 않습니다

서버 주소가 빠졌거나 올바르지 않습니다. 링크를 보낸 사람에게 서버를 다시 공유해 달라고 하세요.

이름과 주소는 링크를 만든 사람이 정한 것이며 MsgCraft가 확인한 것이 아닙니다. 이 페이지는 링크의 # 뒤에 있는 이름과 주소를 이 브라우저 안에서만 읽습니다. # 뒤의 내용은 웹 서버로 가지 않으며, 이 페이지는 아무것도 저장하거나 보내지 않습니다.
